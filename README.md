# Pomodoro Timer for GATE 2027 Preparation

A full-featured Pomodoro timer application designed specifically for GATE 2027 preparation.

## Features

- ⏱️ **Pomodoro Timer** - Study, short break, and long break modes
- 📊 **Daily Statistics** - Track study time, sessions, and breaks
- 📝 **Session Logs** - Detailed time-wise logs of all sessions
- 🎵 **Sound Settings** - Customizable sounds with test functionality
- 🎯 **Subject Tracking** - Track time spent on different subjects
- 📌 **Popout Mode** - Keep timer visible while watching lectures
- 🧘 **Zen Mode** - Minimalist interface for focused study
- ⚙️ **Customizable Settings** - Adjust durations, targets, and preferences
- 💾 **Persistent Data** - All data saved locally in browser

## Installation

```bash
# Clone the repository
git clone <repository-url>
cd pomodoro-timer

# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm build

Usage
Select a subject from the dropdown or add a new one

Start the timer - Click START or press Spacebar

Track sessions - Timer automatically switches between study and breaks

View logs - Check your study history in the session logs

Popout mode - Click the 📎 icon to popout the timer

Zen mode - Click 🧘 for distraction-free studying

Keyboard Shortcuts
Space - Start/Pause timer

Escape - Close popout window
